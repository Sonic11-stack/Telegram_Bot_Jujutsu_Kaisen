# JujutsuKaisenContentBot

Telegram-бот для читателей манги «Магическая битва». В боте можно посмотреть цены на печатные тома и сохранить место, на котором остановились при чтении.

## Возможности

- Выбор тома с 0-го по 15-й. Бот показывает обложку выбранного издания.
- Запрос цены на Яндекс Маркете, Ozon или Wildberries.
- Сохранение одной заметки на чат. Укажите том, главу и страницу в одном сообщении, а затем откройте «Прогресс чтения».
- Переход к онлайн-чтению по ссылке из меню.

Заметки хранятся в памяти и сбрасываются при перезапуске бота. Получение цен зависит от доступности страниц и их разметки. Для Wildberries бот показывает только основную цену, если её удалось извлечь. Обычная цена для Яндекс Маркета в текущей версии рассчитывается приблизительно.

## Технологии

- Python 3.12 и pyTelegramBotAPI для команд, кнопок и обработки сообщений.
- DrissionPage и Chromium для чтения цен со страниц товаров.
- python-dotenv для чтения конфигурации.
- Docker Compose для сборки и запуска.

## Запуск в Docker

1. Запустите Docker Desktop или Docker Engine с Compose.
2. В корне проекта создайте `.env` из шаблона. В PowerShell выполните `Copy-Item .env.example .env`. В Bash выполните `cp .env.example .env`.
3. Получите токен тестового бота у [@BotFather](https://t.me/BotFather) командой `/newbot` или используйте токен своего бота. Впишите его в `.env` в переменную `botKey`. Имя переменной чувствительно к регистру.

   ```dotenv
   botKey=ВСТАВЬТЕ_СЮДА_ТОКЕН
   ```

   Достаточно одной переменной. Храните настоящий токен только в своём `.env`.

4. Соберите и запустите контейнер из папки с `compose.yaml`.

   ```bash
   docker compose up --build
   ```

   Образ устанавливает Chromium. Бот получает сообщения через polling, поэтому пробрасывать порты не требуется.

5. Для фонового запуска используйте `docker compose up -d --build`. Логи открываются командой `docker compose logs -f bot`. Чтобы остановить контейнер, выполните `docker compose down`.

Если в логах появляется ошибка Telegram `409 Conflict`, проверьте, не запущен ли второй экземпляр бота с тем же токеном.

## Что проверить

1. Напишите боту `/start` и нажмите «Да».
2. Откройте «Узнать цены на тома», введите `1` и убедитесь, что бот прислал обложку. Выберите маркетплейс и проверьте ответ о цене.
3. Вернитесь в меню, откройте «Сохранить страницу», отправьте `Том 1, глава 3, страница 42` и проверьте результат в разделе «Прогресс чтения».
4. Откройте «Прочитать онлайн» и проверьте, что кнопка открывает ссылку.
